🔑 Sistema de Acesso
Acesso padrão — senha institucional fornecida pelo NPM/SAA.

Acesso edição — credenciais de gestão, fornecidas pelo administrador do sistema.

Para solicitar ou redefinir credenciais, contate o NPM.

Escala — React + Supabase + Vercel + Auth. CI/CD por área.
